Research notes

Methodology

Every number the system produces, and how it is computed.

Home
01

Vegetation index (VARI)

Every pixel of the selected imagery is converted to the Visible Atmospherically Resistant Index — a greenness measure computed from standard RGB bands, so no infrared sensor is required.

VARI = (G − R) / (G + R − B + ε)

Values are min-max normalized to [0, 1] before clustering.

02

Elbow method for k

K-Means is fitted for k = 1…9 on a downsampled pixel set. The optimal cluster count is the k with maximum perpendicular distance from the chord connecting the first and last WCSS points.

k* = argmaxk  d(WCSSk,  line1→9)

You can override k* manually per analysis.

03

Cluster quality (silhouette)

Each result is scored with the silhouette coefficient on a 5,000-pixel sample — how similar a pixel is to its own zone versus the next-best zone.

s = (b − a) / max(a, b)  ∈ [−1, 1]

> 0.5 is considered well separated; the stored score lets you compare runs across fields and seasons.

04

Soil-tank water balance

Each zone’s cluster centre maps to a soil class (sandy / loamy / clayey) with a field-capacity table. The deficit is scaled by the current root depth of a 200 mm profile.

D = (FC − θ) × Zr  ·  N = D − R7d/2

Half of the 7-day forecast rain is credited against the demand; if rain covers the deficit the run time drops to zero.

05

Run time

Net irrigation requirement is converted to valve-open minutes at a nominal application rate of 15 mm/hour.

t (min) = N / 15 × 60

The ESP32 receives this per zone from /api/zones/<farm_id>.

06

Imagery pipeline

Map selections pull an exact bounding-box window from Esri World Imagery (free, no API key). Uploads accept any aerial screenshot. Both paths converge on the same clustering code.

bbox → export → VARI → K-Means → zones

Tested to z22 overzoom — imagery beyond native z18 is upscaled rather than blanked.
